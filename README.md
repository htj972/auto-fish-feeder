# 智能自动喂鱼器

面向家庭鱼缸的自动喂食项目，包含机械结构、PCB设计和ESP32-C3固件。设备使用N20减速电机驱动螺旋轴送料，通过运行时长调节投喂量，支持每日定时任务、按键投喂、OLED显示和Web配置。

本文件介绍整个项目。固件的接线、编译、使用和测试说明见 **[esp32/README.md](esp32/README.md)**。

## 项目组成

| 部分 | 当前方案 |
|---|---|
| 主控 | ESP32-C3-FH4，封装内4 MB Flash，当前固件固定80 MHz |
| 送料 | 圆筒料仓与4叶片螺旋轴，约50 mL储料空间 |
| 动力 | N20减速电机，单向高电平有效驱动控制 |
| 显示 | 0.91英寸OLED，固件按SSD1306、128×32、I²C地址0x3C实现 |
| 充电与电池检测 | TP4056充电状态输入、电池电压分压采样 |
| 配置方式 | ESP32热点配网、局域网Web页面 |
| 固件环境 | PlatformIO + Arduino |

单次投喂量需要结合实际电机转速、饲料颗粒和螺旋结构标定；配置的秒数不直接代表饲料重量。

## 从哪里开始

### 查看机械设计

- 查看整机：打开 [自动喂鱼器.STEP](自动喂鱼器.STEP)。
- 查看OLED参考尺寸：打开 [OLED_091_38x12_no_header.stp](OLED_091_38x12_no_header.stp)。
- 准备打印：在切片软件中导入 [3mf导出](3mf导出/) 下对应零件，核对尺寸、摆放、支撑和打印参数。
- 修改机械结构：使用SOLIDWORKS打开本地零件或装配源文件；交换模型用于查看和跨软件传递。

仓库说明未给出经过验证的材料、层高、支撑及打印机参数，请根据实际装配间隙检查打印设置。

### 查看电路

使用Altium Designer打开 [PCB/feedfish.PrjPcb](PCB/feedfish.PrjPcb)，结合原理图和PCB文件检查供电、驱动与接口。`feed.zip` 为归档文件，使用前请检查其内容与当前设计版本，不直接认定其为最新生产输出。

### 编译固件

在VS Code中使用PlatformIO打开 **`esp32` 子目录**，或在项目根目录执行：

```powershell
cd esp32
pio run
```

烧录并查看日志：

```powershell
pio run -t upload --upload-port COM实际端口
pio device monitor -b 115200 --port COM实际端口
```

固件使用ESP32-C3原生USB CDC，GPIO18/19需要连接USB数据线。仅连接充电电源的USB接口无法提供固件日志。更完整的下载和接口说明见 [固件README](esp32/README.md#编译烧录使用)。

## 设备操作

| 操作 | 行为 |
|---|---|
| 正常运行时按住按键2秒 | 显示确认进度，满2秒启动投喂 |
| 投喂中松手 | 停止本次按键投喂 |
| 不足2秒松手 | 取消本次操作 |
| 持续按住 | 最多运行30秒，之后必须松手再按 |
| 待机双击按键 | 显示IP地址5秒；未联网显示OFFLINE |
| 上电前按住按键，并保持3秒 | 进入配网，这一轮按住和释放不启动投喂 |
| 首次开机或WiFi连接失败 | 开启配置热点，OLED显示SSID、PASS和WEB地址 |

配网时连接设备热点，访问OLED给出的Web地址，扫描并选择家庭2.4GHz WiFi，再输入密码。联网成功后OLED显示局域网IP，可在同一网络中打开设备管理页；支持mDNS的环境也可尝试 `http://fishfeeder.local/`。

Web页面支持：

- 最多8组每日投喂任务，分别启用、设定时间和动作时长。
- 以秒为单位设置投喂时长，范围0.1～30秒。
- 按保存的手动时长投喂，以及立即停止。
- OLED亮度1～100%预览与保存，重启恢复。
- WiFi扫描与配网、设备状态及报警查看。

## 硬件接线概览

| 功能 | ESP32 GPIO | 说明 |
|---|---|---|
| 电机控制 | GPIO10 | 驱动器使能，高电平有效 |
| 实体按键 | GPIO5 | 低电平有效，按键接GND |
| OLED SCL | GPIO3 | I²C时钟 |
| OLED SDA | GPIO4 | I²C数据 |
| TP4056 CHRG | GPIO20 | 充电状态，低电平有效 |
| TP4056 STDBY | GPIO21 | 充电完成状态，低电平有效 |
| 电池电压 | GPIO2 | 电池正极→100kΩ→采样点→100kΩ→GND |
| 原生USB | GPIO18 / GPIO19 | 分别为D− / D+ |

接线参数以 [esp32/include/board_config.h](esp32/include/board_config.h) 为准。N20应通过合适的电机驱动器供电，不能直接接GPIO；TP4056状态支路需核实对ESP32的电平兼容性。详细电气限制见 [固件接线说明](esp32/README.md#必须配置的接线)。

## 固件入口与运行方式

[esp32/src/main.cpp](esp32/src/main.cpp) 负责初始化与循环调度，各硬件和功能模块分别放在同目录的独立文件中。

启动时依次完成CPU频率检查、引脚验证、电机安全输出、按键、电源检测、参数读取、OLED、WiFi、时间同步和Web服务初始化，最后启动独立按键任务。

运行时分为三个执行部分：

- 主循环：处理电源采样、报警、定时任务、OLED内容变化、WiFi和Web请求。
- 独立按键任务：每5ms检测按键，处理2秒确认和松手停止，避免网页处理拖慢响应。
- 电机定时器：限制单次运行时长，与主循环独立调度。

CPU固定80MHz。OLED保留上一帧，画面不变时不重复传输；充电使用静态闪电，只有进度条、滚动文字及其他实际内容变化才触发更新。

## 测试与当前限制

固件已经过编译、格式检查和桌面逻辑测试；测试文件位于 [esp32/tests](esp32/tests/)。桌面测试覆盖按键、任务相关输入、电源状态、显示更新、亮度保存和网页交互，不替代整机验收。

本项目仍需结合实际硬件验证：

- 投喂时长与出料重量、螺旋堵料及饲料适配。
- 电机启动电流、供电稳定性、充电温升和ESP32温度。
- 网络变化、断电重启和长时间运行下的定时任务。
- OLED型号、亮度、电池电压标定与打印件装配效果。

当前没有电流、转速或料位传感器，不能可靠检测堵转、缺料。电池百分比为电压估计，无电池状态也有识别限制。设备无独立掉电保持时钟，冷启动需联网校时后才执行自动任务；Web配网已实现，AirKiss未实现。
